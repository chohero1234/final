## 프로젝트 소개
> 본 프로젝트는 사용자가 복용하려는 영양제를 카메라로 인식하고, AI(MobileNetV2) 모델이 해당 
영양제의 종류와 복용 적합 시간(낮/밤)을 판별하는 시스템입니다. 아두이노와 연동하여 현재 시간에 
맞는 영양제라면 복용 바구니로 분류하고, 맞지 않는 경우에는 경고 알람을 통해 사용자의 오복용을 
방지하는 것을 목표로 합니다.

## 시스템 구조

```
[카메라]
   │
   ▼
[PC]
  ├─ Vision AI 모델 (MobileNetV2)
  │    └─ 객체 인식 결과 출력
  │
  └─ 시리얼 통신 (USB)
         │
         ▼
    [Arduino]
      ├─ LED(RED)
      └─ LED(GREEN)

```
